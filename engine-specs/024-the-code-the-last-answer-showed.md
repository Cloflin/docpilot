# 024 — The code the last answer showed

> **Статус: измерено, не принято.** Два варианта «сводки прошлого хода» прогнаны
> A/B на follow-up записях через OpenRouter (`openai/gpt-4o-mini`). Первый
> ухудшил `answerF1`, второй лёг в шум контрольного плеча. Без правки модель и так
> воспроизводит код прошлого ответа в 7 из 8 записей — его приносят чанки,
> которые 013 праймит. Код откачен; спека остаётся, чтобы идею не повторяли без
> новых данных.

## Problem

`condenseAnswer` (`prompt.ts`, 022) режет прошлый ответ до 360 символов и
заменяет фенс, который не влез, заглушкой. Источники в транскрипт попадают только
как id чанков. Гипотеза: follow-up вида «добавь туда locale» теряет код, к
которому обращается, и ссылку, на которой он стоял.

Повод — ответ с сайта Stripo: русский вопрос про локаль, ответ «документация не
охватывает» с минимальным конфигом. Разбор показал, что это промах поиска, а не
памяти: раздел `parts/params#locale` есть в индексе, но русский вопрос не делит с
ним ни одного токена (L=0), а `text-embedding-3-small` не поднимает его в top-8.

## Variants measured

**V1 — отдельное user-сообщение перед вопросом.** Обёртка с инструкциями («может
быть не связано», «использовать только если excerpts не отвечают», «не
evidence»), вопрос, источники заголовком и адресом, код прошлого ответа дословно
(≤1500), пометка для ответа без цитат.

**V2 — внутри assistant-сообщения последней пары, только на follow-up**
(`gateResult.channel === 'composed'`). Скелет `condenseAnswer` плюс застабленные
фенсы целиком плюс строка `Sources: Title — href`. Без обёртки и инструкций.

## Measurement

Набор — follow-up записи golden (34) и, для V2, ещё 8 записей «повтори код из
прошлого ответа» (4 с русским вопросом), которые в golden не добавлены. Индекс
`a02ccb5b`, dense через OpenRouter. Переключатель A/B — eval-only env, как
`DOCPILOT_HISTORY_CONDENSE`.

V1, по одному прогону на плечо, 34 записи:

| | A | V1 |
|---|---|---|
| answerF1 | 0.362 | 0.307 |
| identifierRecall | 0.356 | 0.301 |
| supportPrecision | 0.96 | 0.976 |
| negatives caught | 1/6 | 3/6 |
| prompt tokens / turn | 9.5k | 8.4k |

По записям: 2 лучше, 9 хуже, 17 без изменений. Ответы V1 короче (760 против 860
символов) и перефразированы — обёртка перед вопросом читается моделью как
предупреждение.

V2, 42 записи, A прогнан дважды для шума:

| | A1 | V2 | A2 |
|---|---|---|---|
| answerF1 | 0.315 | 0.307 | 0.322 |
| answerF1, 8 записей с кодом | 0.249 | 0.260 | 0.269 |
| identifierRecall | 0.431 | 0.287 | 0.338 |
| citationRecall | 0.528 | 0.571 | 0.542 |
| answer over-refusal | 0 | 1 | 0 |

Шум A1↔A2: 0.007 по `answerF1`, 0.09 по `identifierRecall`. V2 не выходит из
него ни по одной метрике в лучшую сторону; `identifierRecall` ниже обоих
контрольных. Нужный ключ (`reasoning: false`, `ragBase`, `fontMono`…) и код
прошлого ответа есть в ответах A в 7 из 8 записей с кодом.

## Decision

Не принято. Память между ходами на этом наборе держат 013 (цитированные чанки
прошлого хода) и 022 (скелет прошлого ответа). Исходный дефект — поиск по
русскому вопросу, и чинится он там.

## What would reopen it

- Набор, где follow-up ссылается на код, которого НЕТ в документации (модель
  собрала его сама), и A проваливает такие записи.
- Модель слабее `gpt-4o-mini`, на которой A теряет код при живом 013.
- Многократные прогоны, показывающие выход V2 из шума контрольного плеча.
