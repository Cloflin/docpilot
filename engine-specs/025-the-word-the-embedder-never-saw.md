# 025 — The word the embedder never saw

> **Кратко.** Словарь (`vocabulary`) переписывает только лексический канал:
> `локаль` становится `locale` для BM25, а dense канал по-прежнему эмбеддит сырой
> русский вопрос. `rank()` упорядочивает слитый пул только по dense cosine, так
> что раздел, который лексика ставит первым, выпадает из top-8. Теперь
> `embedQuery` дописывает к вопросу строку с каноническими терминами, которые
> назвали его алиасы. Запросов не добавляется; без словаря ничего не меняется.

## Problem

Вопрос с сайта Stripo: «подскажи, как мне добавить свою локаль при инициации в
конфиг?». Корпус английский, эмбеддер `text-embedding-3-small`, раздел
`editor-configuration/parts/params#locale` в индексе есть. Модель ответила
«документация не охватывает» — на excerpts, где этого раздела не было.

С русским словарём (`docpilot vocabulary` плюс ручные алиасы `локаль`,
`инициации`, `конфиг`) лексический канал ставит `params#locale` первым. Итоговая
выдача — нет:

```
lexical : #1 params#locale  #3 params#localepatch
hybrid  : #1 social-networks… … #6 params#localepatch   (params#locale absent)
```

Причина — `rank()` (`retriever.ts`): RRF выбирает пул из `FUSED` = 12, затем
`mmr()` при `MMR_LAMBDA` 1.0 сортирует его по dense cosine — «RRF selects, dense
orders». Лексика заводит раздел в пул, dense cosine сырого русского вопроса
выталкивает его за k.

## Research

Тот же вопрос с канонами вместо алиасов, один embed-запрос: hybrid `#1
localepatch`, `#3 locale`. С канонами, ДОПИСАННЫМИ строкой после вопроса, —
тот же результат. Дописывание выбрано: слова читателя остаются, эмбеддер видит
оба языка, а ошибочный алиас добавляет термин, а не стирает смысл.

Рычаги отклонены:

- `MMR_LAMBDA` < 1 или RRF-порядок для пула — меняет ВСЕ ходы, измерен на
  английском golden и выбран 1.0 (`retriever.ts`, решение 2026-08-12).
- Пин лексического #1 — второй порядок поверх двух существующих, и `L` у
  англоязычного вопроса с редким идентификатором тоже бывает высоким.
- Перевод вопроса моделью — +1 запрос на каждый ход.

## Decision

- `glossQuery(text)` в `text.ts`: те же проходы, что у лексики — самая длинная
  объявленная фраза в позиции, иначе один токен по стему. Каноны, названные
  алиасами, дописываются строкой `\n<canon>, <canon>` в порядке появления, по
  одному разу. Канон, уже стоящий в вопросе, не повторяется — английский вопрос
  словами корпуса эмбеддится как раньше.
- Применяется в ОБОИХ местах, где эмбеддится запрос: `embedQuery` (панель, eval,
  calibrate, bench, tune) и `prefetch.ts` (батч eval). Векторы должны совпадать
  бит в бит.
- `setVocabulary` строит `gloss` (фраза → канон как написан) и `glossStems`
  (стем → канон) из тех же пар.
- `DOCPILOT_GLOSS=0` — eval-only контроль A/B, как `DOCPILOT_HISTORY_CONDENSE`.
  Не ключ конфига.

## Measurement

Stripo, индекс `29065bc0` со словарём (101 терм, 230 алиасов),
`eval --gate-only`, golden 61 запись (16 с русским вопросом). Без модели —
детерминированно.

| | `GLOSS=0` | gloss |
|---|---|---|
| recall@8 | 0.811 | **0.833** |
| MRR | 0.478 | **0.488** |
| recall@8 [Russian] | 0.750 | **0.833** |
| MRR [Russian] | 0.318 | **0.356** |
| retrieval F1 | 0.291 | **0.312** |

Изменились три русские записи, все к лучшему (q-47 recall 0→1; q-51, q-54 MRR
вверх). Из 45 английских у двух сдвинулся порядок внутри выдачи, метрики — нет.

## Cost and risk

- Ноль запросов; несколько десятков символов к эмбед-входу.
- Dense G русского вопроса растёт (q-47: 0.68 → 0.81). `tau` откалиброван без
  gloss — после обновления пакета нужен `calibrate --refresh`. При `guard.mode:
  'off'` (умолчание с 1.3) гейт не отказывает, риск — только устаревший `tau`.
- Вопросы openers эмбеддятся на билде без gloss. Они англоязычные, и канон, уже
  стоящий в вопросе, не дописывается, поэтому их векторы не сдвигаются.
- Плохой алиас дописывает неверный термин. Это та же цена, что словарь уже
  платит в лексике; файл — черновик, который автор правит.
- Откат: убрать вызов в двух местах.

## Checks

`test/gloss.test.js`: без словаря — тождество; каноны по порядку и по разу;
самая длинная фраза первой; канон, уже стоящий в вопросе, не повторяется;
вопрос без алиасов не меняется; `embedQuery` отправляет дописанный текст.

## What this does not do

Не меняет лексический канал, `rank()`, `tau` и doc-side векторы. Не помогает
корпусу без словаря.
