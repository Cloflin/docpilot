# Harborline

> Harborline is a hosted background job queue and cron scheduler for web apps: enqueue jobs over an HTTP API or the Node.js and Python SDKs, let your workers pull them, and get retries with backoff, a DLQ, delayed jobs, schedules, webhooks and Prometheus metrics. These docs cover API v3 (latest 3.4.0); v2 reached end of life on 2026-06-30.

Every page describes v3. Code samples use Node.js (TypeScript) and Python; keys in samples are placeholders such as hl_live_xxx and whsec_xxx.

## Guides

- [Enqueue jobs](/guides/enqueue.md): Add jobs from Node.js, Python or curl: enqueue options, the 256 KB payload size limit, job ids and enqueue errors.
- [Write a worker](/guides/workers.md): Process jobs with pull-based workers: concurrency, heartbeats for long-running jobs, graceful shutdown on deploys (SIGTERM, Kubernetes), shell-script workers.
- [Retries and backoff](/guides/retries.md): Automatic retries of failed jobs: maxAttempts, exponential, linear or fixed backoff, jitter, PermanentError to stop retrying, manual retry.
- [Dead-letter queue](/guides/dead-letter.md): The DLQ for failed jobs that ran out of retries (poison messages): 14-day retention, inspect, replay or purge them, or turn the DLQ off.
- [Delayed jobs](/guides/delayed-jobs.md): Run a job later or at an exact time, up to 30 days ahead; cancel or reschedule it; when to use a cron schedule instead.
- [Schedules](/guides/schedules.md): Cron jobs and recurring tasks: cron syntax, time zones and daylight saving time, overlapping runs, missed runs (no backfill), plan limits.
- [Idempotency](/guides/idempotency.md): Prevent duplicate jobs: deduplicate retried enqueue requests with idempotency keys (24 h window) and make handlers safe to run twice; there is no exactly-once.
- [Batches](/guides/batches.md): Bulk enqueue up to 500 jobs or 5 MB per call, handle partial failures (207 Multi-Status), and import large backlogs.
- [Concurrency and rate limits](/guides/concurrency.md): Limit parallel jobs per queue or per customer (groupKey), throttle job starts, FIFO ordering, no job priorities, and API 429 rate limits.
- [Pause, drain and purge](/guides/queue-control.md): Stop processing a queue for maintenance (pause), stop accepting jobs but finish the backlog (drain), or clear, flush or empty pending jobs (purge).
- [Webhooks](/guides/webhooks.md): Get notified about job and queue events: add an endpoint, event types, the 10-second timeout, and delivery retries (8 over 24 hours).
- [Verify webhook signatures](/guides/webhook-signatures.md): Validate the Harbor-Signature HMAC-SHA256 header with your whsec_ signing secret in Node.js or Python; roll the secret; the old v2 X-Harbor-Sig.
- [Regions and migration](/guides/regions.md): Data residency: us-east-1, eu-central-1 (EU, Frankfurt) and ap-southeast-2 endpoints, and moving a project to another region with harbor migrate.
- [Observability](/guides/observability.md): Monitoring and alerting: Prometheus metrics (queue depth, latency, dead jobs), job logs, OpenTelemetry trace propagation, the dashboard.
- [Client-side encryption](/guides/encryption.md): End-to-end (E2E) encryption of job payloads so Harborline never sees PII or other sensitive data: AES-256-GCM with your own key, key rotation, limits.
