# Roadmap to 3.0

**No 3.0 package is published yet; the 2.x line stays the current version on npm.** This page follows the work toward 3.0. The first two phases, the shared document pipeline and the HTML extractor, are already in 2.2.0: see the [changelog](/changelog). Everything else below is a plan, not a feature of the version you can install.

The progress, the latest update and the roadmap are the GitHub pre-release [`roadmap-3.0`](https://github.com/Cloflin/docpilot/releases/tag/roadmap-3.0), read when this site is built. The note is updated at the end of every phase.
